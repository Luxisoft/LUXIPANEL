# Security

Never commit `.env`, personal tokens, private keys, keystores, service accounts, user files or store credentials. The ignore rules cover installation state and generated output. Example environments contain empty secret values; the installer generates secrets for each installation. Native connection profiles ask for the user's own server URL and login.

Do not post sensitive evidence in public issues. LOG keeps full sanitized evidence locally and publishes only the selected sanitized report. Public code contributions are scanned, tested in isolated checks and reviewed before release.

For a security vulnerability, contact support@luxisoft.com with a minimal description and no credentials. Coordinate disclosure privately before creating a public report. Third-party dependency licenses and update policies remain applicable.
