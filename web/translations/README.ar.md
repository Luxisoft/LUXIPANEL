# LUXIPANEL

تمت المراجعة في 13 أكتوبر 2026

يعمل LUXIPANEL على خادم Linux الخاص بك ويدير الموارد المحلية وأهداف SSH. يدير LP-LICENSE-SERVER الحسابات والمدفوعات والرموز وكتالوج الوحدات والخدمات التحريرية على luxipanel.com. إنشاء حساب لا يثبّت لوحة ولا يسجّل خادمًا.

## قبل التثبيت

تحتاج إلى Debian/Ubuntu وصلاحيات مسؤول واسم مضيف وDNS يعمل. تتطلب الحزم الحالية Node.js 22.12 أو أحدث وتحدد pnpm 11.5.0. يجب توفير Redis وnginx والخدمات التي تستخدمها الوحدات المفعّلة. راجع install.sh أولًا لأنه يثبّت الاعتماديات ويغيّر إعدادات النظام.

## التثبيت وتسجيل الدخول

شغّل المثبّت من مستودع LUXIPANEL مع نطاقك. استخدم --https للعنوان العام المحمي بـTLS أو --cloudflare عند الحاجة. اضبط DNS وشهادة صالحة ثم افتح /login بمستخدم Linux موجود. يمكن لأول مستخدم مؤهل ضمن sudo/wheel أن يصبح مسؤول اللوحة. يوجد وضع استضافة ذاتية واحد؛ إعداد managed القديم ليس مسار التثبيت الحالي.

```bash
sudo bash install.sh --domain panel.example.com --https
```

## الوصول المحلي

تتحقق اللوحة من مستخدم Linux وتطبّق الأدوار وصلاحيات الوحدات. بيانات حساب الموقع ومفاتيح API لا تستبدل دخول Linux. يعمل المنفّذ المحلي على الجهاز الذي يستضيف LUXIPANEL.

## اختر الهدف قبل التنفيذ

اختر الخادم المحلي أو اتصال SSH داخل اللوحة. تعمل الملفات والطرفية والخدمات والعمليات المتوافقة على الهدف المختار وفق القدرات والصلاحيات. تحقّق من الاسم قبل الكتابة أو إعادة التشغيل أو الحذف.

## إضافة هدف SSH واستخدامه

أدخل المضيف والمنفذ ومستخدم SSH وبيانات الاعتماد في محدد الخوادم باللوحة. تُحفظ البيانات مشفرة على اللوحة لا في سجل الموقع المحذوف. تحقّق من الهدف واختره واختبر قراءة قبل التعديل. نجاح SSH لا يضمن دعم جميع الوحدات على كل الأنظمة.

## تشخيص الاتصال

افحص الشبكة ومنفذ SSH وبيانات الاعتماد وصلاحيات المستخدم البعيد. العناوين الخاصة مقيّدة بسياسة الخادم؛ SERVERS_ALLOW_PRIVATE إعداد مسؤول للشبكات الخاصة المشروعة. لا تعطّل التحقق من المضيف ولا تكشف الأسرار لتجاوز خطأ. أعد الاتصال إذا انتهت الجلسة.

## إنشاء مفتاح API باسم

افتح الأمان → API KEY في حساب الموقع، وأكمل فحوص الأمان وأدخل اسمًا واضحًا. انسخ السر المعروض وأدخله عبر API KEY في LUXIPANEL المثبت. لا تختَر خادمًا أو IP أو بيانات SSH على luxipanel.com. يعرّف المفتاح حسابك للخدمات المسموح بها.

## تدوير المفتاح أو إلغاؤه

يظهر السر الكامل عند الإنشاء أو التدوير فقط. حدّثه في جميع التثبيتات التي تستخدمه بعد التدوير. الإلغاء يوقف التفويض ويلغي اشتراكات الوحدات النشطة المرتبطة بالمفتاح. لا تنشره في الصور أو السجلات أو المستودعات أو رسائل الدعم.

## تثبيت الوحدات وإدارتها

افتح الوحدات لعرض الكتالوج والصلاحيات والاعتماديات والتوفر. فعّل أو ثبّت بحسب دورك. تختلف متطلبات الوظائف المدمجة ووحدات المتجر. راجع السعر والشروط الفعلية قبل الاشتراك المدفوع.

## ضبط التكاملات داخل اللوحة

اضبط Cloudflare لـDNS والمناطق، وGitHub للمستودعات، وExpo لـEAS، ومزودي المساعد وموصلاته عند تفعيلها. لكل تكامل بياناته وصلاحياته. استيراد الخوادم السحابية والنطاقات الفرعية المُدارة من الموقع لم يعد مسار الإعداد الحالي.

## الهاتف: اتصال مباشر باللوحة

أضف عنوان LUXIPANEL مثبت، واختر الاتصال وسجّل الدخول بمستخدم اللوحة/Linux. يستخدم التطبيق الحالي شاشات React Native أصلية للوحدات. يحفظ تذكّر الدخول بيانات الجلسة في تخزين آمن وليس كلمة مرور Linux. تعتمد الوظائف على الخادم المختار وصلاحياته.

## سطح المكتب: ملفات تعريف وتبويبات

احفظ اسم اللوحة وعنوانها، واختبر الاتصال وافتح تبويبًا. يعرض Desktop واجهة اللوحة في عرض Electron معزول. تشترك تبويبات الملف نفسه في الجلسة، بينما تخزين الملفات المختلفة منفصل. تغيير العنوان يمسح التخزين السابق. إغلاق النافذة يبقي التطبيق في علبة النظام؛ الخروج ينهيه.

## التحديث والاستعادة

انسخ الإعدادات وبيانات الاعتماد المشفرة احتياطيًا. احتفظ بمفتاح الخزنة؛ تغييره يمنع قراءة البيانات القديمة. نفّذ بناء مشروع واحد في كل مرة على الجهاز. مع Astro نظّف dist واستخدم NODE_OPTIONS=--max-old-space-size=2560 ثم أعد تشغيل العملية وافحص HTTP. عند تغيير بيئة PM2 أعد تقييم ecosystem باستخدام --only و--update-env.

## تقرير مفيد عن المشكلة

أرفق المنتج وإصداري العميل واللوحة والوقت والهدف والخطأ الدقيق وخطوات إعادة المشكلة والنتيجة المتوقعة. استخدم صورًا وسجلات منقحة. لا ترسل كلمات المرور أو المفاتيح الخاصة أو API كاملة أو ملفات تعريف الجلسة أو رموز استعادة العاملين.
