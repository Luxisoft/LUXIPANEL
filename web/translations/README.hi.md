# LUXIPANEL

13 अक्टूबर 2026 को समीक्षा

LUXIPANEL आपके Linux सर्वर पर स्थानीय संसाधन और SSH लक्ष्य प्रबंधित करता है। LP-LICENSE-SERVER luxipanel.com पर खाते, भुगतान, टोकन, मॉड्यूल सूची और संपादकीय सेवाएँ चलाता है। खाता बनाने से पैनल स्थापित या सर्वर पंजीकृत नहीं होता।

## स्थापना से पहले

Debian/Ubuntu, प्रशासक पहुँच, होस्ट नाम और कार्यशील DNS चाहिए। वर्तमान पैकेज Node.js 22.12 या नया तथा pnpm 11.5.0 निर्दिष्ट करते हैं। Redis, nginx और सक्रिय मॉड्यूल की सेवाएँ उपलब्ध हों। install.sh पहले पढ़ें: यह निर्भरताएँ स्थापित और सिस्टम विन्यास बदलता है।

## स्थापना और प्रवेश

LUXIPANEL रिपॉज़िटरी से अपने डोमेन के साथ इंस्टॉलर चलाएँ। सार्वजनिक TLS के लिए --https या उपयुक्त होने पर --cloudflare उपयोग करें। DNS और वैध प्रमाणपत्र के बाद /login पर मौजूदा Linux उपयोगकर्ता से प्रवेश करें। पहला पात्र sudo/wheel उपयोगकर्ता प्रशासक बन सकता है। एक स्व-होस्टेड मोड है; पुराना managed विन्यास वर्तमान प्रक्रिया नहीं है।

```bash
sudo bash install.sh --domain panel.example.com --https
```

## स्थानीय पहुँच

पैनल Linux उपयोगकर्ता प्रमाणित करके भूमिकाएँ और मॉड्यूल अधिकार लागू करता है। वेब प्रमाण और खाता API कुंजी Linux प्रवेश का विकल्प नहीं हैं। स्थानीय निष्पादक LUXIPANEL होस्ट मशीन पर काम करता है।

## कार्रवाई से पहले लक्ष्य चुनें

पैनल में स्थानीय सर्वर या SSH चुनें। फ़ाइल, टर्मिनल, सेवाएँ और समर्थित कार्रवाइयाँ क्षमताओं व अधिकारों के अनुसार चुने लक्ष्य पर चलती हैं। लिखने, पुनः शुरू करने या मिटाने से पहले लक्ष्य का नाम जाँचें।

## SSH लक्ष्य जोड़ें

पैनल के सर्वर चयन में होस्ट, पोर्ट, SSH उपयोगकर्ता और प्रमाण दें। प्रमाण उसी पैनल पर एन्क्रिप्टेड रहते हैं, हटाई गई वेबसाइट सूची में नहीं। लक्ष्य सत्यापित करें, चुनें और बदलाव से पहले पढ़ने की जाँच करें। SSH सभी ऑपरेटिंग सिस्टम पर सभी मॉड्यूल की गारंटी नहीं है।

## कनेक्शन की जाँच

नेटवर्क, SSH पोर्ट, प्रमाण और दूरस्थ उपयोगकर्ता अधिकार जाँचें। निजी पते सर्वर नीति से सीमित हैं; SERVERS_ALLOW_PRIVATE वैध निजी नेटवर्क के लिए प्रशासक सेटिंग है। त्रुटि टालने के लिए होस्ट सत्यापन बंद या रहस्य उजागर न करें। समाप्त SSH सत्र दोबारा जोड़ें।

## नाम वाली API कुंजी बनाएँ

वेब खाते में सुरक्षा → API KEY खोलें, सुरक्षा जाँच पूरी करें और स्पष्ट नाम दें। दिखाया गया रहस्य कॉपी करके स्थापित LUXIPANEL के API KEY में डालें। luxipanel.com पर सर्वर, IP या SSH प्रमाण नहीं चुनना है। कुंजी अधिकृत सेवाओं के लिए खाता पहचानती है।

## कुंजी बदलना या रद्द करना

पूरा रहस्य केवल निर्माण या रोटेशन पर दिखता है। बदलने के बाद सभी उपयोग करने वाले इंस्टॉलेशन अपडेट करें। रद्द करने से प्राधिकरण रुकता और उस कुंजी की सक्रिय मॉड्यूल सदस्यताएँ समाप्त होती हैं। कुंजी स्क्रीनशॉट, लॉग, रिपॉज़िटरी या सहायता संदेश में न रखें।

## मॉड्यूल स्थापित और प्रबंधित करें

पैनल में मॉड्यूल खोलकर सूची, अधिकार, निर्भरताएँ और उपलब्धता देखें। भूमिका अनुसार सक्षम या स्थापित करें। अंतर्निहित और marketplace मॉड्यूल की शर्तें अलग हो सकती हैं। भुगतान सदस्यता से पहले वर्तमान मूल्य और शर्तें पढ़ें।

## पैनल में एकीकरण सेट करें

Cloudflare में DNS व ज़ोन, GitHub में रिपॉज़िटरी, Expo में EAS तथा सक्षम सहायक प्रदाता/कनेक्टर सेट करें। प्रत्येक को अपने प्रमाण और अधिकार चाहिए। पुराने वेबसाइट क्लाउड सर्वर आयात और प्रबंधित सबडोमेन अब सेटअप प्रक्रिया नहीं हैं।

## मोबाइल: सीधे पैनल से जुड़ें

स्थापित LUXIPANEL का URL जोड़ें, कनेक्शन चुनें और पैनल/Linux उपयोगकर्ता से प्रवेश करें। वर्तमान ऐप React Native मॉड्यूल स्क्रीन उपयोग करता है। प्रवेश याद रखने पर सुरक्षित भंडारण में सत्र डेटा रहता है, Linux पासवर्ड नहीं। क्षमताएँ चुने सर्वर और अनुमतियों पर निर्भर हैं।

## डेस्कटॉप: प्रोफ़ाइल और टैब

पैनल नाम और URL सहेजें, कनेक्शन जाँचकर टैब खोलें। Desktop अलग Electron दृश्य में पैनल का वेब इंटरफ़ेस दिखाता है। एक प्रोफ़ाइल के टैब सत्र साझा करते हैं; अलग प्रोफ़ाइल का भंडारण अलग है। URL बदलने पर पुराना भंडारण मिटता है। विंडो बंद करने पर ट्रे रहती है; बाहर निकलने से ऐप बंद होता है।

## अपडेट और पुनर्प्राप्ति

विन्यास और एन्क्रिप्टेड प्रमाणों का बैकअप लें। वॉल्ट कुंजी सुरक्षित रखें; बदलने पर पुराने प्रमाण नहीं पढ़े जा सकेंगे। मशीन पर एक समय में एक प्रोजेक्ट बनाएँ। Astro में dist साफ करके NODE_OPTIONS=--max-old-space-size=2560 उपयोग करें, फिर प्रक्रिया पुनः शुरू करके HTTP जाँचें। PM2 वातावरण बदलने पर --only और --update-env के साथ ecosystem पुनः मूल्यांकित करें।

## उपयोगी समस्या रिपोर्ट

उत्पाद, क्लाइंट-पैनल संस्करण, समय, लक्ष्य, सटीक त्रुटि, दोहराने के चरण और अपेक्षित परिणाम दें। रहस्य हटाकर स्क्रीनशॉट या लॉग जोड़ें। पासवर्ड, निजी कुंजी, पूरी API कुंजी, कुकी या दो-कारक रिकवरी कोड न भेजें।
