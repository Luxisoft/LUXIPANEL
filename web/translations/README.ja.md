# LUXIPANEL

2026年10月13日確認

LUXIPANELは利用者のLinuxサーバーで動作し、ローカル資源とSSH接続先を管理します。LP-LICENSE-SERVERはluxipanel.comのアカウント、支払い、トークン、モジュールカタログ、編集サービスを提供します。アカウント作成だけではパネルのインストールやサーバー登録は行われません。

## インストールの前に

管理者権限、ホスト名、正常なDNSを持つDebian/Ubuntu環境が必要です。現在のパッケージはNode.js 22.12以上を要求し、pnpm 11.5.0を指定しています。Redis、nginx、有効なモジュールが使うサービスを準備してください。install.shは依存関係を導入してシステム設定を変更するため、実行前に確認します。

## インストールとログイン

LUXIPANELリポジトリから自分のホスト名でインストーラーを実行します。公開先がTLSの場合は--https、必要に応じて--cloudflareを使います。DNSと有効な証明書を設定し、/loginで既存のLinuxユーザーとしてログインします。条件を満たす最初のsudo/wheelユーザーが管理者になれます。現在はセルフホストの単一モードで、旧managed設定は現行手順ではありません。

```bash
sudo bash install.sh --domain panel.example.com --https
```

## ローカルアクセス

パネルはLinuxユーザーを認証し、ロールとモジュール権限を適用します。Web認証情報やアカウントAPIキーはLinuxログインの代わりにはなりません。ローカル実行はLUXIPANELを設置したマシン上で行われます。

## 操作前に対象を選ぶ

パネルでローカルサーバーまたはSSH接続を選択します。ファイル、端末、サービスなどの対応操作は、機能と権限に従い選択先で実行されます。書き込み、再起動、削除の前に接続先名を確認してください。

## SSH接続先を追加

パネルのサーバー選択からホスト、ポート、SSHユーザー、認証情報を追加します。認証情報はそのパネルで暗号化保存され、廃止されたWeb一覧には保存されません。接続先を確認して切り替え、変更前に読み取りを試します。SSH接続できても全OSで全モジュールが動くとは限りません。

## 接続の診断

到達性、SSHポート、認証情報、リモートユーザーの権限を確認します。プライベートアドレスはサーバーポリシーで制限され、SERVERS_ALLOW_PRIVATEは正当な内部ネットワーク用の管理者設定です。問題回避のためにホスト確認を無効化したり秘密を公開したりしないでください。期限切れのSSHセッションは再接続します。

## 名前付きAPIキーを作成

Webアカウントのセキュリティ → API KEYを開き、安全確認を完了して分かりやすい名前を付けます。表示された秘密鍵文字列をコピーし、インストール済みLUXIPANELのAPI KEYから入力します。luxipanel.comでサーバー、IP、SSH認証情報を選ぶ必要はありません。キーは許可されたサービスでアカウントを識別します。

## キーの更新と失効

キー全文は作成またはローテーション時だけ表示されます。更新後は使用する全インストール先で置き換えてください。失効すると認可が止まり、そのキーに関連する有効なモジュール購読が解約されます。画面写真、ログ、リポジトリ、サポート連絡にキーを含めないでください。

## モジュールの導入と管理

パネルのモジュールでカタログ、権限、依存関係、利用可否を確認し、自分のロールに従って有効化・導入します。組み込み機能とマーケットプレイス製品で条件は異なります。有料契約前に実際の価格と条件を確認してください。

## パネルで連携を設定

CloudflareはDNS・ゾーン、GitHubはリポジトリ、ExpoはEASを設定します。アシスタントのプロバイダーやコネクターは有効な場合に利用できます。各連携には固有の認証情報と権限が必要です。旧Webクラウドサーバー取り込みや管理サブドメインは現行の設定経路ではありません。

## モバイル：パネルへの直接接続

導入済みLUXIPANELのURLを追加し、接続先を選んでパネル/Linuxユーザーでログインします。現行アプリのモジュール画面はReact Native製です。ログイン記憶はセッション情報を安全な領域に保存し、Linuxパスワードは保存しません。利用できる機能は接続先と権限によって変わります。

## デスクトップ：プロファイルとタブ

導入済みパネルの名前とURLを保存して接続テストを行い、タブを開きます。DesktopはそのWeb画面を分離されたElectronビューで表示します。同じプロファイルのタブはセッションを共有し、別プロファイルの保存領域は独立します。URL変更で以前の保存内容が削除されます。ウィンドウを閉じてもトレイに残り、終了操作でアプリが終了します。

## 更新と復旧

設定と暗号化された認証情報をバックアップします。保管庫の鍵を変更すると既存の認証情報が読めなくなるため、鍵を保管してください。ビルドは1台につき1つずつ行います。Astroはdistをクリーンにし、NODE_OPTIONS=--max-old-space-size=2560を指定してビルド後に再起動とHTTP確認を行います。PM2の環境を変更した場合は--onlyと--update-envでecosystemを再評価します。

## 役立つ報告を作成

製品、クライアント・パネル版、時刻、対象サーバー、正確なエラー、再現手順、期待結果を伝え、秘密を除いた画面やログを添付します。パスワード、秘密鍵、APIキー全文、Cookie、二要素の復旧コードは送らないでください。
