# LUXIPANEL

১৩ অক্টোবর ২০২৬ পর্যালোচিত

LUXIPANEL আপনার Linux সার্ভারে স্থানীয় সম্পদ ও SSH লক্ষ্য পরিচালনা করে। LP-LICENSE-SERVER luxipanel.com-এর অ্যাকাউন্ট, অর্থপ্রদান, টোকেন, মডিউল ক্যাটালগ ও সম্পাদকীয় সেবা চালায়। অ্যাকাউন্ট খুললেই প্যানেল ইনস্টল বা সার্ভার নিবন্ধিত হয় না।

## ইনস্টলের আগে

Debian/Ubuntu, প্রশাসনিক প্রবেশাধিকার, হোস্টনাম ও কার্যকর DNS দরকার। বর্তমান প্যাকেজে Node.js 22.12 বা পরের সংস্করণ এবং pnpm 11.5.0 উল্লেখ আছে। Redis, nginx ও সক্রিয় মডিউলের সেবাগুলো থাকতে হবে। আগে install.sh পড়ুন: এটি নির্ভরতা ইনস্টল ও সিস্টেমের সেটিং বদলায়।

## ইনস্টল ও প্রবেশ

LUXIPANEL রিপোজিটরি থেকে নিজের ডোমেইন দিয়ে ইনস্টলার চালান। প্রকাশ্য TLS-এর জন্য --https বা প্রযোজ্য হলে --cloudflare ব্যবহার করুন। DNS ও বৈধ সার্টিফিকেট সেট করে /login-এ বিদ্যমান Linux ব্যবহারকারী দিয়ে প্রবেশ করুন। প্রথম যোগ্য sudo/wheel ব্যবহারকারী প্রশাসক হতে পারেন। একটি স্ব-হোস্টেড মোড আছে; পুরোনো managed সেটআপ বর্তমান পদ্ধতি নয়।

```bash
sudo bash install.sh --domain panel.example.com --https
```

## স্থানীয় প্রবেশ

প্যানেল Linux ব্যবহারকারী যাচাই করে ভূমিকা ও মডিউলের অনুমতি প্রয়োগ করে। ওয়েব পরিচয়তথ্য ও অ্যাকাউন্ট API কী Linux প্রবেশের বিকল্প নয়। স্থানীয় নির্বাহক LUXIPANEL হোস্ট মেশিনে কাজ করে।

## কাজের আগে লক্ষ্য বাছুন

প্যানেলে স্থানীয় সার্ভার বা SSH সংযোগ বাছুন। ফাইল, টার্মিনাল, সেবা ও সমর্থিত কাজ সক্ষমতা ও অনুমতি অনুযায়ী নির্বাচিত লক্ষ্যেই চলে। লেখা, পুনরায় চালু বা মুছে ফেলার আগে নাম পরীক্ষা করুন।

## SSH লক্ষ্য যোগ ও ব্যবহার

প্যানেলের সার্ভার নির্বাচনে হোস্ট, পোর্ট, SSH ব্যবহারকারী ও পরিচয়তথ্য দিন। তথ্য প্যানেলে এনক্রিপ্ট করা থাকে, সরানো ওয়েব তালিকায় নয়। লক্ষ্য যাচাই ও নির্বাচন করে পরিবর্তনের আগে পড়ার পরীক্ষা করুন। SSH সব অপারেটিং সিস্টেমে সব মডিউলের নিশ্চয়তা দেয় না।

## সংযোগ পরীক্ষা

নেটওয়ার্ক, SSH পোর্ট, পরিচয়তথ্য ও দূরবর্তী ব্যবহারকারীর অধিকার পরীক্ষা করুন। ব্যক্তিগত ঠিকানা সার্ভার নীতিতে সীমিত; SERVERS_ALLOW_PRIVATE বৈধ ব্যক্তিগত নেটওয়ার্কের প্রশাসনিক সেটিং। সমস্যা এড়াতে হোস্ট যাচাই বন্ধ বা গোপন তথ্য প্রকাশ করবেন না। মেয়াদোত্তীর্ণ সেশন আবার যুক্ত করুন।

## নামযুক্ত API কী তৈরি

ওয়েব অ্যাকাউন্টে নিরাপত্তা → API KEY খুলে নিরাপত্তা পরীক্ষা শেষ করুন এবং বোঝা যায় এমন নাম দিন। দেখানো গোপন মান কপি করে ইনস্টল করা LUXIPANEL-এর API KEY-তে দিন। luxipanel.com-এ সার্ভার, IP বা SSH পরিচয়তথ্য বাছতে হয় না। কী অনুমোদিত সেবায় অ্যাকাউন্ট শনাক্ত করে।

## কী বদলানো বা বাতিল

সম্পূর্ণ গোপন মান শুধু তৈরি বা রোটেশনের সময় দেখা যায়। বদলানোর পর সব ব্যবহারকারী ইনস্টলেশনে আপডেট করুন। বাতিলে অনুমোদন বন্ধ হয় এবং কীটির সক্রিয় মডিউল সাবস্ক্রিপশন বাতিল হয়। স্ক্রিনশট, লগ, রিপোজিটরি বা সহায়তা বার্তায় কী দেবেন না।

## মডিউল ইনস্টল ও পরিচালনা

প্যানেলের মডিউল অংশে ক্যাটালগ, অনুমতি, নির্ভরতা ও প্রাপ্যতা দেখুন। ভূমিকা অনুযায়ী সক্রিয় বা ইনস্টল করুন। অন্তর্নির্মিত ও marketplace মডিউলের শর্ত ভিন্ন হতে পারে। অর্থপ্রদত্ত সাবস্ক্রিপশনের আগে প্রকৃত মূল্য ও শর্ত পড়ুন।

## প্যানেলে ইন্টিগ্রেশন সেট করুন

DNS ও জোনের জন্য Cloudflare, রিপোজিটরির জন্য GitHub, EAS-এর জন্য Expo এবং সক্রিয় সহকারী প্রদানকারী/কানেক্টর সেট করুন। প্রতিটির নিজস্ব পরিচয়তথ্য ও অধিকার লাগে। পুরোনো ওয়েব ক্লাউড সার্ভার আমদানি ও পরিচালিত সাবডোমেইন বর্তমান সেটআপ নয়।

## মোবাইল: সরাসরি প্যানেলে প্রবেশ

ইনস্টল করা LUXIPANEL-এর URL যোগ করুন, সংযোগ বেছে প্যানেল/Linux ব্যবহারকারী দিয়ে প্রবেশ করুন। বর্তমান অ্যাপ React Native-এর নিজস্ব মডিউল স্ক্রিন ব্যবহার করে। মনে রাখার সুবিধা সুরক্ষিত স্থানে সেশন তথ্য রাখে, Linux পাসওয়ার্ড নয়। সুবিধা নির্বাচিত সার্ভার ও অনুমতির ওপর নির্ভরশীল।

## ডেস্কটপ: প্রোফাইল ও ট্যাব

প্যানেলের নাম ও URL সংরক্ষণ করুন, সংযোগ পরীক্ষা করে ট্যাব খুলুন। Desktop পৃথক Electron ভিউতে প্যানেলের ওয়েব ইন্টারফেস দেখায়। একই প্রোফাইলের ট্যাব সেশন ভাগ করে, আলাদা প্রোফাইলের সঞ্চয়স্থান পৃথক। URL বদলালে আগের তথ্য মুছে যায়। উইন্ডো বন্ধ করলে ট্রে থাকে; প্রস্থান করলে অ্যাপ বন্ধ হয়।

## আপডেট ও পুনরুদ্ধার

সেটিং ও এনক্রিপ্ট করা পরিচয়তথ্য ব্যাকআপ করুন। ভল্টের কী রাখুন; বদলালে পুরোনো তথ্য পড়া যাবে না। প্রতি মেশিনে একবারে একটি প্রকল্প বিল্ড করুন। Astro-তে dist পরিষ্কার করে NODE_OPTIONS=--max-old-space-size=2560 ব্যবহার করুন, তারপর প্রক্রিয়া পুনরায় চালু করে HTTP পরীক্ষা করুন। PM2 পরিবেশ বদলালে --only ও --update-env দিয়ে ecosystem পুনর্মূল্যায়ন করুন।

## কার্যকর সমস্যার প্রতিবেদন

পণ্য, ক্লায়েন্ট-প্যানেল সংস্করণ, সময়, লক্ষ্য, সঠিক ত্রুটি, পুনরুৎপাদনের ধাপ ও প্রত্যাশিত ফল জানান। গোপন তথ্য বাদ দিয়ে ছবি বা লগ দিন। পাসওয়ার্ড, ব্যক্তিগত কী, সম্পূর্ণ API কী, কুকি বা দুই-ধাপ পুনরুদ্ধার কোড পাঠাবেন না।
